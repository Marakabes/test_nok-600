Конфиденциальность

Политика конфиденциальности

1. Какие данные мы собираем

Приложение НЕ собирает персональные данные пользователей. Все данные хранятся локально на вашем устройстве:

📊 Прогресс обучения
❌ Совершенные ошибки
⚙️ Настройки приложения

2. Локальное хранение данных

Мы используем localStorage вашего браузера для сохранения:

Результатов тестирования
Настроек отображения
Истории ошибок для повторения

Эти данные не передаются на сервер и доступны только вам.

3. Файлы cookie

Приложение не использует файлы cookie для отслеживания пользователей.

4. Сторонние сервисы

Мы не используем аналитику и не передаем данные третьим лицам.

5. Удаление данных

Для полного удаления всех данных:

Используйте функцию "Сбросить прогресс" в приложении
Или очистите данные сайта в настройках браузера
